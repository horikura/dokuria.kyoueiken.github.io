ドクリア共栄圏 ウェブサイト（創作・架空設定）

【設置】
index.html / dodoria.png / dodoriasan.gif を同じフォルダに配置し、
index.html を開くか、GitHub Pages 等にアップロードします。

【編集】
index.html をメモ帳・VS Code 等で編集してください。
サイトカラーは先頭の <style> 内 :root で変更できます。
JavaScript・外部CSS・外部サービスは使用していません。

【画像について】
画像はHTMLの <img> 要素ではなく CSS背景として表示し、
通常のドラッグ保存や画像要素の右クリック保存をしにくくしています。
ただし、画像をブラウザで表示する以上、開発者ツール・通信解析・
スクリーンショット等による複製を完全に防ぐことはできません。
第三者による転載を防ぎたい場合は、透かしや低解像度版の採用、
公開範囲の制限等も検討してください。
